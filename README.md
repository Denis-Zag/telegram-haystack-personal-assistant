# Telegram Haystack Personal Assistant

Персональный Telegram-ассистент использует Haystack Agent, сохраняет только
сообщения пользователя в Pinecone и сам вызывает внешние инструменты для
актуальных данных. Бот умеет учитывать прошлый контекст, получать погоду,
рассказывать факты о кошках и отправлять проанализированное изображение собаки.

## Для работодателя

Проект показывает практическую сборку AI-агента, а не обычного чат-бота:
семантическую память, tool calling, мультимодальный запрос, работу с внешними
API, изоляцию данных пользователей, тестирование и безопасную конфигурацию.

Проверены реальные вызовы Haystack-инструментов, ProxyAPI, Pinecone, Telegram,
Open-Meteo, Cat Fact Ninja и Dog CEO API. Постоянный Telegram polling во время
автоматической проверки не запускался.

## Что умеет бот

- отвечает на обычные сообщения через Haystack Agent;
- ищет связанные прошлые фразы пользователя в Pinecone;
- сохраняет только исходный текст пользователя;
- получает актуальную погоду через Open-Meteo;
- получает случайный факт о кошках через Cat Fact Ninja;
- получает изображение собаки через Dog CEO API;
- анализирует изображение мультимодальной моделью и отправляет фото с подписью;
- показывает число записей командой `/memory_status`;
- очищает только память текущего пользователя командой `/clear`.

Календарь, напоминания, Notion и другие дополнительные интеграции в проект не
входят.

## Архитектура

```text
Сообщение Telegram
        │
        ├── поиск похожих прошлых сообщений
        │              ↓
        │      Pinecone namespace пользователя
        │
        ├── сохранение исходного сообщения пользователя
        │
        └── Haystack Agent
                ├── get_current_weather → Open-Meteo
                ├── get_random_cat_fact → Cat Fact Ninja
                └── get_and_analyze_dog_image
                         ├── Dog CEO API
                         └── ProxyAPI vision
                ↓
          текст или фотография с подписью
```

Поиск в Pinecone выполняется до сохранения текущего сообщения. Поэтому запрос
не находит сам себя, а получает только более ранний контекст.

## Как устроена память

Для каждого Telegram-пользователя создаётся отдельный Pinecone `namespace`.
Открытый `user_id` в его название не попадает: используется SHA-256-хеш.

В документе Pinecone находятся:

- `content` — исходный текст пользователя;
- `type=user_message`;
- `telegram_message_id` — для защиты от повторного сохранения сообщения.

Ответы ассистента, результаты инструментов и изображения в Pinecone не
записываются. Стабильный ID документа позволяет перезаписать повторно
обработанное сообщение вместо создания дубликата.

## Инструменты агента

### Погода

`get_current_weather(city)` выполняет два запроса:

1. Geocoding API находит координаты города.
2. Forecast API возвращает температуру, ощущаемую температуру, ветер, осадки и
   код погодных условий.

Open-Meteo не требует отдельного ключа для используемого учебного сценария.

### Факт о кошках

`get_random_cat_fact()` получает случайный факт через `catfact.ninja/fact`.
Агент может перевести и естественно сформулировать результат на русском языке.

### Изображение собаки

`get_and_analyze_dog_image()` получает HTTPS-ссылку Dog CEO API, передаёт
изображение мультимодальной модели через ProxyAPI и возвращает два значения:

- URL изображения;
- короткую подпись с предполагаемой породой, признаками и происхождением.

Haystack сохраняет оба значения в состоянии текущего запуска агента. Telegram
получает настоящее изображение с подписью, а не только текстовое описание.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements-dev.txt
```

Проект проверен на Python 3.12.9.

## Настройка

Создайте локальный файл `.env`:

```powershell
Copy-Item .env.example .env
```

Заполните три секрета:

```dotenv
TELEGRAM_BOT_TOKEN=
PROXYAPI_KEY=
PINECONE_API_KEY=
```

Основные несекретные настройки уже находятся в `.env.example`:

- модель чата `openai/gpt-4o-mini`;
- embedding-модель `openai/text-embedding-3-small`;
- размерность Pinecone `1536`;
- метрика `cosine`;
- serverless-регион `aws / us-east-1`;
- число результатов памяти `5`.

Файл `.env` исключён из Git. Ключи, токены и тексты сообщений не выводятся в
логи.

## Проверка без запуска бота

```powershell
python -m pytest -q --basetemp .pytest-tmp -p no:cacheprovider
python -m ruff check .
python -m compileall -q app bot.py preflight.py tests
python -m pip check
```

Офлайн-тесты не обращаются к Telegram, ProxyAPI, Pinecone или внешним API.

## Живая предварительная проверка

Обычная проверка:

```powershell
python preflight.py
```

Полная проверка самостоятельного выбора инструментов агентом:

```powershell
python preflight.py --with-agent-tools
```

Дополнительный прямой анализ изображения:

```powershell
python preflight.py --with-vision
```

`preflight.py` проверяет Telegram `getMe`, внешние API, ProxyAPI, семантическую
память и Haystack Agent. Для Pinecone используется временный пользовательский
namespace, который удаляется в блоке `finally`. Telegram polling не запускается.

Параметры `--with-agent-tools` и `--with-vision` выполняют дополнительные
запросы к модели и могут расходовать платный лимит ProxyAPI.

## Запуск

```powershell
python bot.py
```

На одном Telegram-токене должен работать только один polling-процесс.

## Проверочный сценарий домашнего задания

1. Отправить `/start` и `/memory_status`.
2. Написать: «Я живу в Казани и люблю гулять после 19:00».
3. Задать несколько других вопросов.
4. Спросить: «Где я живу и когда предпочитаю гулять?».
5. Проверить, что ответ опирается на найденное сообщение из Pinecone.
6. Спросить актуальную погоду в Москве.
7. Попросить случайный факт о кошках.
8. Попросить показать и описать случайную собаку.
9. Проверить, что Telegram получил изображение и подпись.
10. Выполнить `/clear` и убедиться через `/memory_status`, что память пуста.
11. Повторить вопрос о месте проживания: удалённый факт не должен восстановиться.

Для проверки изоляции два разных Telegram-аккаунта должны увидеть разные
значения `/memory_status` и не находить сообщения друг друга.

## Безопасность и ограничения

- Это учебный проект, а не сервис для чувствительных персональных данных.
- Текст пользователя передаётся ProxyAPI для создания embedding и сохраняется в
  Pinecone, поэтому в бот не следует отправлять секреты и конфиденциальные данные.
- Определение породы по случайному изображению является предположением модели.
- Доступность функций зависит от сторонних API и интернет-соединения.
- Проект не содержит календаря, напоминаний, Notion и административной панели.
- Для публичного сервиса потребуются квоты, мониторинг, политика хранения данных
  и дополнительная защита от злоупотреблений.
